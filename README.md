# Tu GoPro en 8 pasos

Guía visual, en español, para aprender a usar la GoPro HERO13 Black desde cero: prenderla, poner la memoria, grabar, pasar los videos y viajar con ella. Pensada para leerse en el teléfono.

Sitio: https://gopro.kapitec.pro

- Estático: HTML + CSS + SVG propios, sin build. Se publica desde `docs/` con GitHub Pages.
- Los textos se redactaron a partir del manual oficial de GoPro HERO13 Black (edición en español). GoPro y HERO son marcas de GoPro, Inc. Este sitio no es de GoPro.
- Los videos se incrustan desde YouTube (canales de terceros en español) y no forman parte del repositorio.
